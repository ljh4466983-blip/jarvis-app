# 자비스 — 통화 일정 비서 (Android)

통화가 끝나면 휴대폰 기본 통화녹음 파일을 자동으로 찾아
**녹취 → 요약 → 일정 추출 → "이렇게 저장합니다" 확인 → 수정 → 승인 → 구글 캘린더 등록**까지 처리합니다.
휴대폰이 켜져 있는 동안 계속 동작하고, 재부팅해도 자동으로 다시 켜집니다.

## 동작 흐름

1. 통화 종료 → 삼성 기본 통화녹음이 `내장저장소/Recordings/Call/통화 녹음 상대_YYMMDD_HHMMSS.m4a` 저장
2. 자비스 감시 서비스가 새 파일을 감지(즉시 + 10분마다 재확인)
3. OpenAI 음성인식으로 녹취록 생성
4. Claude가 녹취록 + 통화 시각 + 앞으로 2주 기존 일정을 함께 보고 일정 추출
   - "내일/다음 주 화요일" → 통화 시각 기준 실제 날짜로 변환
   - 바뀐 약속은 마지막 합의만, 취소된 약속은 제외
   - 애매한 부분(시간 미정, 오전/오후 불분명, 미확정 제안)은 ⚠ 표시, 근거 문장 첨부
5. "일정 N건 확인해 주세요" 알림 → 누르면 확인 화면
   - 상단 **이렇게 저장합니다** 카드: 날짜·시간·제목·장소·대상 캘린더 미리보기
   - 각 일정의 제목·날짜·시간·종일·장소·메모를 직접 수정, 체크 해제로 제외, 직접 추가 가능
   - 기존 일정과 시간이 겹치면 빨간 경고
6. **승인** → 선택한 구글 캘린더에 등록(알림 30분 전 기본) / **거절** → 등록 안 함
7. 매일 아침 8시: 오늘 일정, 겹치는 일정, 확인 대기 건수 브리핑 알림

## 빌드·설치 (PC 1회)

1. [Android Studio](https://developer.android.com/studio) 설치
2. 이 폴더(`jarvis-app`) 열기 → Gradle 동기화가 끝날 때까지 대기
3. 휴대폰: 설정 → 휴대전화 정보 → 소프트웨어 정보 → 빌드번호 7번 탭 → 개발자 옵션 → USB 디버깅 켜기
4. USB 연결 후 ▶ Run (또는 Build → Build APK 후 APK를 휴대폰에 복사해 설치)

## 휴대폰 설정 (1회)

| 항목 | 방법 |
|---|---|
| 자동 통화녹음 | 전화 앱 → ⋮ → 설정 → 통화 녹음 → **자동 통화 녹음** 켜기 (모든 통화) |
| 권한 | 자비스 첫 화면 → "권한 허용하기" (캘린더, 음악 및 오디오, 알림) |
| 꺼지지 않게 | 첫 화면 "배터리 최적화 제외" + 설정 → 배터리 → 백그라운드 사용 제한 → **절전 예외 앱**에 자비스 추가 |
| API 키 | 첫 화면 설정: OpenAI 키(음성인식), Anthropic 키(일정 분석) |
| 캘린더 | 설정에서 등록할 구글 캘린더 선택 (휴대폰에 로그인된 구글 계정 캘린더가 표시됨) |

설정 후 "녹음 파일 직접 골라서 분석"으로 지난 통화 녹음 하나를 넣어 시험해 보세요.
설치 이전 녹음은 자동으로 처리하지 않습니다(일괄 비용 방지).

## 구조

```

  data/Models.kt, Prefs.kt, Times.kt
  ui/MainActivity.kt         상태·설정·통화 기록·7일 일정

```

## 알아둘 점

- **Android 전용, Android 10 이상.** 안드로이드 정책상 다른 앱이 통화 음성을 직접 녹음할 수 없어서, 휴대폰 기본 통화녹음 파일을 읽는 방식입니다. 한국 출시 갤럭시 기준이며, 다른 기종은 설정의 "통화녹음 폴더·파일 키워드"를 녹음 폴더 이름에 맞게 바꾸세요. iPhone은 녹음 파일에 접근할 수 없어 지원하지 않습니다.
- 녹음은 OpenAI·Anthropic 서버로 전송됩니다. 상대방 개인정보가 담길 수 있으니 업무용 기기·계정 정책을 확인하세요. 원본 녹음은 휴대폰에 그대로 두고, 분석용 임시 복사본은 처리 후 지웁니다.
- 25MB를 넘는 녹음(대략 1시간 이상 통화)은 음성인식 한도로 실패합니다.
- API 키는 휴대폰 앱 내부 저장소에 저장됩니다(다른 앱 접근 불가, 루팅 기기 제외).
- 비용은 통화 길이에 비례합니다. 최신 요금은 OpenAI·Anthropic 요금 페이지에서 확인하세요.
- 기존 일정 "변경"은 새 일정으로 제안하고 ⚠로 알려 줍니다. 기존 일정 삭제·이동은 직접 하세요.
